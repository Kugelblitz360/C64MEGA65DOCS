C64 for MEGA65

Keyboard Shortcuts and Multidisks

The MEGA65 keyboard has more keys than a Commodore 64. Some of these keys are put to extra use.

Default settings (customizable)

KeyFunctionComment
CAPS LOCK4x Turbo on/offAlways available, LED shows whether Turbo is on, not customizable
HELPMenuOpens the Core Menu, not customizable
F9Freeze ButtonWhen a .crt that contains a freezer is running
F10 (Shift F9)Mount CartridgeShortcut to the LOAD CRT function
F11Mount Drive #8Shortcut to the Mount Disk in Drive #8 function
F12 (Shift F11)Load PRGQuickly load a .PRG file into memory
F13Volume UpMake stuff louder
F14 (Shift F13)Volume DownMake stuff quieter

Customization and other functions

The menu Advanced Settings -> Keyboard Shortcuts allows to you redefine the six function keys with some other tools.

FunctionDescription
OffDoes nothing
FreezeIf a supported Freezer cartridge is mounted (Action Replay, Final Cartridge III, Super Snapshot V5), the Freeze function is activated.
Mount Drive #XMounts a .d64 or .d81 file into the drive X and returns to the running program (Change Disk)
Next disk drive #XAutomatically mounts the next disk from the current directory. See explanation below.
Load PRGLoads and Runs a .prg file fast (no disk access, direct memory copy)
Load CRTTurns off hardware cartridge, mounts the .crt file as a simulated cartridge and resets the C64.
Flip joysticksSwaps the two joystick ports (for games that expect the joystick in a different port)
Volume up/downRaises or lowers the volume of the C64 output in 5% steps. Hold key to repeat.

A short message at the bottom of the screen (about one second, the C64 keeps running) confirms what happened, for example Volume: 75%, Joystick ports: flipped or Drive 8: Game Disk 2.d64.

If a shortcut cannot do its job, the message tells why: Drive 9 is off, Drive 8 is the internal 1581 (with the physical floppy you swap disks by hand), Drive 8 is still saving (try again a second later) or Drive 8: no other disk image.

Changes done via shortcut (volume, flip joysticks) are also saved in the config file about three seconds after the last change, just like a change in the menu. The key assignments are saved like every other setting, so will be like you set them when you restart the Core.

Multidisk Workflow

Many C64 games and some demos span more than one disk and before it was a chore to swap disks when the game asked you to. With the “Next disk” function you can automate that task.

Preparation

All disks for a game must be in one sub-directory of the SD card. Also make sure you put in one blank disk for save games, as most games require them. The Core can not create extra disks for you. So you have a directory with

  • Game Disk 1a.d64
  • Game Disk 1b.d64
  • Game Disk 2a.d64
  • Game Disk 2b.d64
  • Saved Game.d64

Please make sure that copy you the disks into the directory in that order, preferably one by one. The list is not sorted, the order in which you copy the files will be the order they are swapped. Please keep each game in its own directory.

Set the function key of your choice to “Next disk drive #8” (or #9). (This is not on a function key by default).

Usage

Mount and start with the first disk. When the game asks you to insert the next disk, just press the function key you defined. A status line will show you which file is now mounted, so you can cycle through disks quickly when you need to mount the Saved Game disk from the example above. The last mounted disk will be saved in your Config file.

Before a disk is swapped out, all writes to it need to be finished first. This can give you a short delay and a warning in the status line (as you would not pull out a disk of a 1541 when the drive light is still busy).
